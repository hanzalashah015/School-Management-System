School Management System
A web-based School Management System developed as a BSIT academic
project. The application is designed for administrative use and
helps manage key school operations from one place.
Project Overview
The system focuses on simplifying routine school administration,
organizing records, and maintaining information in a MySQL database
through a PHP-based web interface.
Technologies Used
- PHP --- server-side application logic
- MySQL --- database management
- HTML5 --- page structure
- CSS3 --- styling
- JavaScript --- client-side interactions
- Bootstrap --- responsive interface components
- XAMPP --- local Apache and MySQL development environment
Main Modules
- Student Admission: Add, update, and delete student records
  containing personal and academic details, and manage admission
  information.
- Teacher Management: Register teachers and maintain
  teacher-related information and responsibilities.
- Course Allocation: Manage courses and their relationships with
  students, teachers, and departments.
- Fee Management: Maintain student fee records and payment
  history, with support for fee-related administration.
- Class Timetable: Create and manage class schedules for students
  and teachers while helping avoid scheduling conflicts.
Scope: This version is an admin-focused, web-based application. It
does not include separate student or teacher login portals.

Getting Started
Requirements
- XAMPP or another local environment with Apache, PHP, and MySQL
- A web browser
- A code editor such as Visual Studio Code
Run Locally
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into XAMPP's htdocs directory.
4. Open phpMyAdmin in your browser.
5. Create the project database and import the SQL database file
   included in the repository, if provided.
6. Check the database connection settings in the PHP configuration file
   and update them for your local MySQL setup.
7. Open the project in your browser using a local URL, for example:
   http://localhost/school_management_system/
   Replace school_management_system with the actual project folder
   name. If Apache is configured to use a different port, include that
   port in the URL.
